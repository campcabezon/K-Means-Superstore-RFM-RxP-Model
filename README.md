RxP model (Revenue & Profit) is designed to be a scenario builder which utilizes k-means clustering so show the impact of certain decisions and their respective impacts on Revenue & Profit. 

The RxP model itself is password protected, feel free to reach to request a copy and the password. 

With the Superstore dataset the ideal # of clusters (K), is 3. This provides us three groups... Performers, Potential, & Trailing.

As we proceed with each scenario we can measure the impact on each group...

Scenario A - Increase price on underperforforming sectors by 20%
  It should be noted with the design of the model 20% can be substituted for any value and the sectors which we increase prices on is also fully customizable. 
  For example, you could target
  Top products, +5% 
  Underperforming products, -10%
  Higher prices for specific product groups (such as corporate, consumer, or home office), +25%

Scenario B - Increase units sold by 50% for underperforming sectors
  It should be noted with the design of the model 20% can be substituted for any value and the sectors which we increase units sold is also fully customizable.
